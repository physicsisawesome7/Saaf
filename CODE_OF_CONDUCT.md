# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good faith, and keep discussions about the work. Harassment, personal attacks and discriminatory language are not tolerated in any project space.

**Privacy is part of conduct here.** Never post anyone's real personal data (including your own identifiers) in issues, discussions, PRs or chat.

## Reporting

Report incidents privately to the maintainers by email to **lalit@safearly.com**, or through a GitHub security advisory marked "conduct". Reports are handled confidentially. Maintainers who do not follow or enforce the code of conduct may face consequences decided by other project maintainers.

Enforcement follows the Contributor Covenant community impact guidelines: correction, warning, temporary ban, permanent ban.
