### Added
- **browser-extension 0.2.0**, the first launch-ready plugin: masks personal data before it is sent to ChatGPT, Claude, Gemini, Perplexity, Copilot, DeepSeek, Le Chat and Grok, and on any other site the user turns on from the popup (one-origin optional permission). New: real values are restored in replies on screen only, mid-stream and in loose forms, highlighted with the CSS Custom Highlight API. The vault lives in extension session storage and survives reloads. The dialog lists what was found, partly hidden, with an "always mask" option. Clean messages are no longer delayed. New popup with a per-site switch, mode, reveal switch, counts and "Forget saved values". Bundled with esbuild into Chrome and Firefox packages (`npm run extension` writes `dist/*.zip`), with no web-accessible resources. Includes a test harness page and `STORE.md`.

### Added
- **website**: `/playground`, a working demo anyone can use. Chat with a real model (OpenAI, Anthropic, Gemini, OpenRouter, local Ollama, a local Saaf gateway, or a simulated model needing no key) with masking in the browser, streaming restore, a "view as the model" switch, per-detection evidence, editable policy (shadow mode, threshold, mask/block/warn/allow per type) and a downloadable evidence log with no raw values. File mode masks CSV/TSV (column headers used as context), JSON, JSONL and text up to 25 MB in a Web Worker and restores from a vault file. Keys stay in memory; the page's CSP only allows those provider hosts and localhost.
- **gateway**: `SAAF_CORS_ORIGINS` (off by default) so a browser page can call a gateway on localhost, including Chrome's private-network preflight; exposes `x-saaf-entities` and `x-saaf-mode`.
- **docs**: `docs/try-it.md` (playground, install from GitHub, gateway in two minutes) and `examples/demo/docker-compose.yml` (gateway wired to the playground, OpenAI or offline Ollama upstream).
- **spec 0.2.0**: Aadhaar written as digit words (English, Romanised Hindi, Devanagari), dotted, or spaced digit by digit; spelled-out mobile numbers; hyphenated or spaced PAN; names after KYC labels in Roman and Indian scripts ("Name:", "नाम:", "பெயர்:", "mera naam"); NEFT/IMPS/RTGS as negative context; apostrophes in emails. 23 new shared conformance vectors.
- **plugins/presidio**: `saaf-presidio`, which registers Saaf's recognizers in any Presidio `AnalyzerEngine` (UPI, IFSC, mobile, bank account, ABHA, a PAN validator, a real GSTIN check character) and replaces Presidio's built-in India recognizers.
- **bench**: `fetch` (licence-cleared Naamapadam, HiNER and Razorpay IFSC data with a SHA-256 manifest), `generate-v1` (six named slices), `sweep`, `footprint`; per-slice scoring, warm-up, cold start and ms/KB; Presidio default, tuned and +Saaf adapters; the first head-to-head in `bench/results/v1/`.
- **ci**: every GitHub Action pinned to a commit SHA (`scripts/pin_actions.py`, checked in CI).
- **website**: safearly.com (`apps/website`): a minimal single page covering product, how it works, the live engine demo, features, accuracy, integrations, developers, security and privacy, pricing, FAQ and contact; SEO and hosting files; a Firebase Hosting deploy workflow.
- **brand**: "sun behind the bar" Safearly mark (a saffron sun partly hidden by a green redaction pill) and the `[▬]` Saaf mark, logos, favicons, app icons, social card and extension icons generated by `scripts/make_brand_assets.py`; guidelines in docs/brand.md.
- **spec 0.1.0**: 22 entity types (P0 and P1) in a declarative spec with a JSON schema; 98 shared conformance vectors.
- **core**: normalization with an offset map (NFKC, zero-width characters, homoglyphs, Indic digits, dashes); validators (Verhoeff, Luhn + IIN, PAN, GSTIN, IFSC, UPI handles, mobile, state codes, Udyam); context scoring where the nearest label wins and negative context is clipped to the clause; checksum-assisted OCR repair; overlap resolution.
- **core**: `Saaf` sessions with policy-as-code (mask/hash/block/warn/allow, shadow mode, destination/role rules, per-entity thresholds); label, keyed-HMAC and format-preserving fake tokens; tolerant restore; `restore_json` for tool calls; `StreamRestorer`; cross-turn Aadhaar detection.
- **core**: vaults: in-memory (TTL), SQLite and Redis with AES-GCM, HMAC lookups and crypto-shredding.
- **core**: signed, hash-chained audit records (types and counts only); evidence pack; `saaf` CLI (`scan`, `mask`, `restore`, `entities`, `validate`, `audit verify`, `evidence`); pre-commit hook.
- **js**: TypeScript port with detection, policy subset, mask/restore and streaming restore, passing the shared vectors.
- **gateway**: OpenAI `/v1/chat/completions` and Anthropic `/v1/messages` proxy with streaming restore, per-tenant policies, 403 on block and audit logging.
- **plugins**: LiteLLM guardrail, Open WebUI filter, LangChain wrapper and RAG document masking, MCP server, Claude Code hook, browser extension (warn and mask on submit), n8n node scaffold.
- **apps**: in-browser playground.
- **bench**: IndicPII-Bench generator (6 domains + hard negatives), harness (strict/relaxed P/R/F1, hard-negative FP per 1k tokens, restore round-trip under mangling, latency), corpus v0.

### Fixed
- **spec**: the Indic-script name rule no longer swallows a following verb or particle ("नाम राहुल वर्मा है" → "राहुल वर्मा"). Found in the playground. Saaf's v1 strict micro-F1 moves from 0.711 to 0.713 (precision only); published tables are unchanged until the next full run.
- **plugins/mcp-server**: pin `mcp<2`; MCP SDK 2.x renamed `FastMCP` and broke a fresh install.
- **plugins/presidio**: add the README the package metadata points at; without it `uv sync --all-packages` failed.
- **website**: repository links pointed at a GitHub org that doesn't exist; they now point to github.com/physicsisawesome7/Saaf. Scripts and styles revalidate on every load instead of being cached for a day.
- **core/js**: card validation enforces per-network lengths (a 14-digit account number in the Mastercard range is not a card). A nearer negative label ("order") now cancels a farther positive boost outright.
- **core/js**: streaming restore could emit a closing `]` after a restored value when a word followed the token; tokens now only start at an alphanumeric, `[`, `\` or `+`. Found by property tests.
- **core/js**: negative context (for example "ref" on the next line) no longer suppresses valid detections; scores are rounded to avoid float drift at the threshold. Found by IndicPII-Bench (PHONE_IN F1 0.00 → 1.00).
