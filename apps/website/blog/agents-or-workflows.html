Agents or workflows? How to choose

Lalit Shukla
2 Nov 2026 · Explainer
AgentsWorkflowsDesign

"Should this be an agent or a workflow?" is the first question teams ask when they move past simple Q&A. The short answer: let a model decide when the path isn't known in advance, and draw the path when it is.

The difference

An agent is given a goal, some sources and some tools, and decides for itself which to use and in what order. A workflow is a process you drew: which steps run, in what order, under which conditions, and where a person must sign off. In Smriti a workflow's steps can themselves be agents, so the choice is about who owns the control flow: the model, or you.

When an agent fits

  • The questions vary. A support assistant or a policy desk gets a different question every time, and the right lookups depend on it.
  • The steps are cheap to get wrong. Searching one more source or doing one more calculation costs little.
  • Exploration is the point. A research brief should split the question its own way.

Good agents are narrow: a clear job, a few sources and the fewest tools that do it. Every tool you add is another thing the model can choose wrongly.

When a workflow fits

  • There is a process already. Draft, review, release. Classify, answer, escalate. If you can draw it on a whiteboard, draw it on the canvas.
  • Someone has to sign off. A human approval step is explicit and recorded, not something you hope the model asks for.
  • The same thing happens to many items. A questionnaire with forty questions is a loop, not a forty-turn conversation.
  • A number decides the route. "Over the limit goes to a person" belongs in a condition, not in a prompt.

Using both

Most real processes are a workflow with agents inside. A ticket-triage workflow might use a classic agent to try to answer from runbooks, branch on whether it found an answer, and only then hand off to an agentic step that opens a ticket after approval. The workflow fixes the order and the checkpoints. The agents handle the parts that need judgement.

A useful rule of thumb: start with an agent. When you notice you are writing "first do this, then always do that" into its instructions, it's time for a workflow.

Rules that hold either way

Whichever you choose, the same guarantees apply in Smriti. Every step acts as the person asking. Answers are checked sentence by sentence against what was retrieved. Personal data is masked before any model. And anything that changes data waits for that person's approval. The choice changes who decides the path, never who is allowed to see what.
