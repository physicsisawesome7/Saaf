# safearly.com

The marketing site for **Saaf by Safearly**: plain static HTML/CSS/JS, no build step beyond copying the engine, no third-party requests.

```bash
npm run build --workspace packages/saaf-js   # compile the engine
node apps/website/build.mjs                   # copy it to assets/saaf/
python -m http.server 8080 --directory apps/website
```

| Path | |
|---|---|
| `index.html` | The whole site on one page: hero, how it works, live demo (real engine, in the browser), features, accuracy, integrations, developers, security & privacy, pricing, FAQ, contact |
| `404.html` | Not-found page |
| `assets/styles.css`, `assets/main.js` | Minimal design system (auto light/dark) and behaviour, no dependencies |
| `assets/brand/` | Logos, icons, OG image, generated by `scripts/make_brand_assets.py` |
| `CNAME`, `_headers`, `robots.txt`, `sitemap.xml`, `.well-known/security.txt` | Hosting and SEO |

Deploys to GitHub Pages through `.github/workflows/website.yml` (custom domain `safearly.com`). For strict security headers, serve it through Cloudflare Pages or Netlify, which read `_headers`.

Contact address used on the site and in `security.txt`: `lalit@safearly.com`.
