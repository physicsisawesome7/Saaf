◻

A laptop, no GPU

The CPU profile answers with verified extracts and computes table maths in code. Useful from the first minute, on any machine with Docker.

◼

One consumer GPU

Profiles for 6, 12, 16 and 24 GB cards pick an open-weight model, embeddings and a reranker that fit, and leave room for the cache.

▦

Your servers

PostgreSQL, Qdrant and S3-compatible storage, with stateless API replicas and separate ingestion workers that scale on their own.

⛨

Fully offline

Once installed, nothing needs the internet. Models are open weights you host, and the default ones are Apache-2.0. Outbound requests pass an egress guard.

Questions

Frequently asked.

Is Smriti really open source?

Yes. The whole platform is Apache-2.0, including agents, workflows, integrations and the release gates. There is no paid tier hidden behind the open one. Safearly offers help with pilots and deployments.

Which models does it use?

Any OpenAI-compatible server, chosen per task. The installer starts open-weight Qwen3 models with matching embeddings and a reranker sized for your GPU. With no model at all, it still searches, quotes verified extracts and computes tables.

Does any data leave our network?

Not unless you connect something that sends it. Models run on your hardware. Outbound requests from crawlers and tools pass an egress guard, personal data is masked before anything goes to an external tool, and chat-app replies are masked by default.

How is this different from a chatbot over our PDFs?

Three things: answers are verified sentence by sentence and withheld when they fail; access is enforced for the person asking on every surface; and document versions and amendments are tracked, so you get the rule in force, not just the newest file.

Can we put it in our own app or website?

Yes. Add a widget with one script tag, call any agent through an OpenAI-compatible API, connect assistants such as Claude or IDE agents over MCP, or put agents in Slack, Telegram and Discord.

Is there a hosted version?

Not yet. Smriti is built to run on infrastructure you control. If you'd like help with a pilot, write to us.
