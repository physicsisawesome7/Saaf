Browser extension · v0.2 · beta

Use any AI chat without handing over your personal data.

Saaf checks each message on your device before it is sent. Aadhaar, PAN, card numbers, emails and other identifiers go to the AI as tokens like [PAN_1], and the real values come back in the reply, on your screen only.

Download for Chrome, Edge & Brave How to install Source code

Free and open source (Apache-2.0). Chrome Web Store and Firefox Add-ons listings are on the way. Until then, install it in developer mode in under a minute.

Mask on send. Restore on screen.

1 · Checked before it leaves

When you press Enter or Send, Saaf scans the message on your device. If it finds personal data, it shows you what it found, partly hidden, and asks before anything is sent.

2 · The AI sees tokens

Choose Mask & send and the AI receives [AADHAAR_1] instead of the number. The same value keeps the same token for the whole session, so the AI can still reason about it.

3 · You see the real values

When the reply mentions a token, Saaf swaps the real value back in on your screen, highlighted in violet, even while the answer is still streaming. The AI's servers never get it.

Install in under a minute.

1 · Download

saaf-chrome-0.2.0.zip and unzip it to a folder you will keep.

2 · Open extensions

Go to chrome://extensions (or edge://extensions) and turn on Developer mode.

3 · Load it

Choose Load unpacked and select the unzipped folder. Pin Saaf from the puzzle-piece menu.

4 · Try it

Open ChatGPT or Claude and send a message with a test PAN such as ABCPE1234F.

What it does and does not do.

Private by design

No account, no analytics and no network requests. Real values are kept in the browser's session memory for the extension only, never in the website's page, and are gone when you close the browser. Privacy policy.

Display only

Restored values are shown on your screen. The site's own copy button, chat history and shared links still contain the tokens, which is the point: that is what the AI company stored.

Known limits

It checks typed and pasted text, not uploaded files or images. Names in free text are only caught after a cue like "Mr" or "name:". Sites change their pages often; if one breaks, tell us.

Need this for a whole team?

The extension protects one person's browser. For company-wide AI traffic, the same engine runs as an OpenAI- and Anthropic-compatible gateway, with policies, audit logs and plugins for LiteLLM, Open WebUI, LangChain and MCP.
