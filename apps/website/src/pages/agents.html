Four kinds

Pick how much the agent does on its own.

Classic

Cited lookup

Answers from the agent's sources through the full pipeline: version rules, "as of" dates, amendments and table maths. No model needed for lookups.

Agentic

Uses tools

Decides which tools to call, reads the results and answers with citations to them. Without a model, a rule planner still searches, reads links and calculates.

Research

Plans and verifies

Splits a broad question into two to five parts, answers each with its own verification, and merges them into one cited report.

Guarantees

Why the answers can be trusted.

Acts as the asker

An agent built by someone with wide access never shows more to someone with less. Its sources only narrow what is searched.

Every result is citable

Tool results become numbered passages. The answer is verified sentence by sentence against them, and a failing one is replaced or withheld.

Personal data stays masked

Masked before the model sees the question or a tool result, and before anything goes to an external tool, then restored on screen.

Injected text can't act

After a run reads outside content, every action that changes data waits for approval, whatever the agent's setting.

Everywhere

Share it, schedule it, call it.

Share and publish

Keep it private, share it with everyone or with chosen roles, as a draft or published. Shared conversations hide answers whose sources the viewer can't open.

Run on a schedule

A cron expression and a question. Published agents run as their owner and post the result to a conversation.

Use from code

Per-agent keys work with the OpenAI-compatible endpoint, so any SDK or chat client can call an agent and get its sources.

curl https://smriti.example/v1/chat/completions \
  -H "Authorization: Bearer sk-smriti-…" \
  -d '{"model": "agent/contract-analyst", "messages": [{"role": "user", "content": "What is the liability cap?"}]}'
