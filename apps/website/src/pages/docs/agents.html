Agents and tools

An agent is a saved assistant with its own instructions, sources and tools. Open Agents in the web app. Anyone with the view grant can build a private agent. Sharing one, and connecting external tools, needs curate or administer.

Kinds

KindWhat it doesNeeds a model?
ClassicCited answers from the agent's sources through the full pipeline.No
AgenticA tool loop: the model picks tools, reads results and answers with citations to them.For the full loop; a rule planner works without one

Settings

  • Instructions: who it answers for, tone, what to always include. Platform rules sit above them: cite every factual sentence, treat tool results as data, and say what is missing instead of guessing.
  • Sources: everything the asker may see, or chosen document types and ingestion sources. Sources narrow retrieval; they never widen it.
  • Tools: built-in and connected tools (below).
  • Approval: ask before anything that changes data (default), before every tool call, or never. After reading outside content, changes always need approval.
  • Starter questions, max tool steps, and only answer when supported by citations (on by default).
  • Sharing: only me, everyone, or chosen roles; draft or published.
  • Schedule: a cron expression and a question. Published agents run as their owner and post to a conversation.

The builder's Try it panel runs the agent as it stands in the form, unsaved.

Every connected tool has the roles that may use it and a sensitivity for its results. Credentials are encrypted and never returned. Saving a tool reads its actions from the target, so you see exactly what agents can call.

Conversations and sharing

Chats are saved per person and agent. Share makes a link. Someone who opens it sees only the answers whose cited documents they can open themselves.

API keys

Open an agent's API keys. A key (sk-smriti-…) is shown once, works for that agent only, and acts as the person who created it.

curl https://smriti.example/api/agents/contract-analyst/chat \
  -H "Authorization: Bearer sk-smriti-…" \
  -H "Content-Type: application/json" \
  -d '{"question": "What is the liability cap?", "stream": false}'

The same key works with the OpenAI-compatible endpoint, using the model name agent/<id>. See API, MCP and CLI.
