Integrations

Open Agents → Integrations to put a published agent in a web page, Slack, Telegram or Discord. Creating one needs curate or administer and an agent you can edit. Each has a setup panel with the steps, embed code or webhook URL, and test buttons.

Who an integration answers as

ModeOnBehaviour
FixedallAnswers as the person who created it. Right for public help desks over public documents.
Signed-in userswidgetThe host site's server signs a short-lived token for the logged-in user; the widget answers as them, and approvals work.
Mapped peopleSlack, Telegram, DiscordChat-app user ids mapped to Smriti users by an administrator. Unmapped people are refused.

Checks on answers that leave Smriti

  • Personal data is masked in replies to chat apps, which store every message. On by default.
  • Classified answers stay home. An answer citing documents above the limit (default internal) becomes a link back to Smriti, and the event is audited.
  • Approvals are buttons only the person who asked can press.
  • Inbound requests are verified: Slack signing secret with a 5-minute window, Telegram secret token, Discord Ed25519 signature, widget origin allow-list and rate limit.
The origin check stops other websites from embedding your widget, not a script that copies the URL. A fixed widget is public to anyone who can reach Smriti; use signed-in users for anything private.

Website widget

<script src="https://smriti.example/widget.js"
        data-smriti-widget="wg_…" data-host="https://smriti.example" async></script>

Optional: data-user-token (signed widgets), data-position="left", data-open="true". In JavaScript: SmritiWidget.open(), .close(), .ask(text), .setUserToken(token). It renders in a shadow root, streams cited answers and keeps the conversation for the tab.

Signing a user on your server:

import hashlib, hmac, time
exp = int(time.time()) + 3600
sig = hmac.new(SIGNING_KEY.encode(), f"{user_id}.{exp}".encode(), hashlib.sha256).hexdigest()
token = f"{user_id}.{exp}.{sig}"

Slack

  1. Create an app at api.slack.com/apps with the bot scopes app_mentions:read, chat:write and im:history, and install it.
  2. Paste the bot token and signing secret into Smriti.
  3. Set the Event Subscriptions and Interactivity URLs to the webhook URL, subscribed to app_mention and message.im.

Telegram

  1. Create a bot with @BotFather and paste its token.
  2. Press Connect webhook.

Discord

  1. Paste the Application ID, Public Key and bot token.
  2. Set the Interactions Endpoint URL to the webhook URL, then press Register /ask.
  3. Invite the app with the applications.commands scope.

Bots need Smriti reachable from the internet at SMRITI_PUBLIC_URL. On a closed network, use the widget.
