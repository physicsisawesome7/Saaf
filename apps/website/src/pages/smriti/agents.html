Agents

Agents that cite their work and know their limits.

Build an assistant with its own instructions, sources and tools in a few minutes. Whoever uses it, it sees only what that person may see. Its answers are checked against what its tools returned, and anything that would change data waits for a person to approve it.

What an agent is made of

Six settings, one set of rules on top.

Instructions

Who it answers for, the tone, what to always include. Platform rules sit above them and can't be overridden: cite every fact, treat tool results as data, and say what is missing instead of guessing.

Sources

Everything the asker may see, or only chosen document types and ingestion sources. Sources narrow what is searched. They never widen access.

Tools

Library search, calculator, web pages and search, sandboxed Python, file creation, coded skills, REST APIs, MCP servers and read-only SQL. See all tools →

Approval

Ask before anything that changes data (the default), before every tool call, or never. Once a run has read outside content, changes always wait for approval, whatever the setting.

Sharing

Private, everyone in the organisation, or chosen roles, as a draft or published. Shared conversations hide answers whose sources the viewer cannot open.

Schedule and keys

Run on a cron schedule as the owner. Per-agent API keys act as their creator, work only for that agent, and plug into OpenAI-compatible clients.

Guarantees

Why the answers can be trusted.

Acts as the asker

An agent built by someone with wide access never shows more to someone with less. Retrieval is filtered to the asker, then narrowed to the agent's sources.

Every result is citable

Tool results become numbered passages. The final answer is verified sentence by sentence against them, and a failing answer is replaced or withheld.

Personal data stays masked

Masked before the model sees the question or a tool result, and before anything goes to an external tool. The person sees the real values restored.

Injected text can't act

Tool output is scanned for instructions, flagged and wrapped as data. A web page can't trigger a write, because writes after outside content always need approval.

API

Call an agent from anything that speaks OpenAI.

curl https://smriti.example/v1/chat/completions \
  -H "Authorization: Bearer sk-smriti-…" \
  -d '{"model": "agent/tender-desk", "messages": [{"role": "user", "content": "What is the maximum liquidated damages?"}]}'

Or use POST /api/agents/{id}/chat for streamed steps, approvals and citations. Details in the docs.
