**Description:**

> Use AI chats without handing over your personal data.
>
> Saaf checks each message on your device before it is sent. If it contains an Aadhaar number, PAN, card number, bank account, email, phone number, API key or one of 22 identifier types, Saaf shows you what it found and masks it in one click. The AI receives tokens like [PAN_1] instead of the real values.
>
> When the reply mentions a token, Saaf shows the real value again on your screen, highlighted, even while the answer is still streaming. The AI's servers never receive it.

## Single purpose (Chrome)

Prevents personal data from being sent to AI chat websites, by detecting and masking it in the user's message before sending, and showing the original values in replies on the user's screen.

## Permission justifications (Chrome)

| Permission | Justification |
| --- | --- |
| Host access to the 9 listed AI chat sites | Reads the message being sent to check it for personal data and, if the user chooses, masks it. Restores masked values in replies on screen. |
| `optional_host_permissions` (any https site) | Requested only when the user clicks **Turn on** for a specific site in the popup, one origin at a time, so the protection can be used on other AI chats. |
| `storage` | Saves settings and aggregate counts, and keeps the session vault (token → value) in `storage.session`, which is cleared when the browser closes. |
| `scripting` | Registers and injects the content script on sites the user turned on, without requiring a page reload. |
| `activeTab` | Shows whether the current tab is protected, in the popup. |
| Remote code | None. All code is bundled in the package. |

## Data usage disclosures (Chrome)

- Collects: **none** of the listed categories. Text is processed locally and never transmitted.
- Certify: not sold to third parties; not used for purposes unrelated to the single purpose; not used for creditworthiness or lending.

## Firefox (AMO)

- The manifest declares `data_collection_permissions: { required: ["none"] }` and the add-on ID `saaf@safearly.com`.
- AMO asks for source code when the package is bundled. Upload a zip of the repo, or link to the tagged GitHub source, and include these build steps: `npm ci && npm run extension` (Node 20+), output in `plugins/browser-extension/build/firefox`. esbuild is the only build tool, and the output is not minified.
